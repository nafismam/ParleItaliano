# Curriculum map

The course is organized as a roadmap: start with the building blocks, then follow dependencies into sentences and everyday communication. Each stop is a focused lesson with five checked exercises. The order is a suggested path, so later the reader can show prerequisites and mastery without forcing a learner to study in only one way.

## Editorial progression

The A1 path establishes form and high-frequency phrases. A2 lessons build combinations and past/future expression. The B1 pronoun lessons introduce clitics and the first uses of _ci_ and _ne_. Learners can move between paths once prerequisites are met; this is a curriculum recommendation, not an enforced lock.

## Content model

Each database topic has a stable slug, CEFR level, learning-domain category, reading-time estimate, structured note, key rules and exactly five exercises. Answers and explanations remain server-only. Exercise IDs are stable across seed runs, and updating a lesson does not delete progress. `npm run seed` refreshes the trusted editorial catalog idempotently.
